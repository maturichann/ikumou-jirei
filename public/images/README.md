## ファイル名の規則
- `before1.png`, `before2.png` - 施術前写真
- `top_YYYY-MM-DD.png` - 頭頂部の写真（日付付き）
- `part_YYYY-MM-DD.png` - 分け目の写真（日付付き）
- `mji_YYYY-MM-DD.png` - M字部分の写真（日付付き）
